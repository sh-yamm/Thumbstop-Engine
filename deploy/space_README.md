# Thumbstop Engine

Reads a microdrama screenplay and finds the 20–60 second moments that work as promos: a hook in the first 3 seconds,
a cliffhanger at the end, and sense for a stranger. Then it judges, ranks and captions them.

- **Demo:** the full run on a 50-episode show, with a replay of every stage from the saved model answers.
- **Live run:** the real pipeline on NVIDIA's free tier, on chosen episodes or uploaded screenplays.
- **How it works:** the stages, the rules and the models.

Code, prompts and the full documentation: https://github.com/sh-yamm/Thumbstop-Engine
